Run an analysis from the menus

Type or paste data into the worksheet, or open a sample dataset from the Data menu. Results appear here as tables you can copy into Word or Excel. Text variables are treated as categories; empty cells are missing values.

Prefer typing? The command line below accepts Stata-style commands such as regress wage educ exper, robust. Type help to list them.

New here? Open Help in the menu bar for step-by-step instructions on every analysis.
